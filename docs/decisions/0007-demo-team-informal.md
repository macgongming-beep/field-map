# 비공식은 일정의 팀에 배정한다

- 상태: 데모 검증 중, 운영 미적용
- 결정일: 2026-09-30
- 이전 결정: 0006의 비공식 영속 후속 작업을 이 단계에서 진행한다.

팀원마다 개인 배정을 복제하던 방식 대신 calendar_events.assignment_team_informal에
안정적인 team_key별 asset ID 목록을 저장한다. 사람별 수신 목록은 현재 팀 구성에서
파생하며 DB에 복제하지 않는다. NULL은 기존 개인 배정 이력, 객체는 팀 모델이다.

데모 편집에서는 비공식 선택도 초안이다. 배정 공유 RPC가 카드·봉사 형태·비공식과
팀 멤버를 한 트랜잭션으로 공유한다. 팀원 이동/탈퇴/팀 삭제는 공유 후 수신 목록에
반영된다. 식당은 기존 개인 배정 방식 그대로다. 팀 이름·색 영속은 별도 후속이다.

전환한 일정은 구버전 카드 RPC/직접 배정 표 쓰기를 차단한다. 읽기 권한은 바꾸지 않는다.
신규 RPC는 세션·일정 관리 권한·참가자·동일 팀 내용·비공식 카드 존재·공유시각 충돌을 검사한다.
빈 팀(멤버 없음)은 수신자가 없으므로 공유에 포함하지 않는다.

사용자 승인으로 데모의 오늘/예정 일정 개인 비공식 배정만 백업 후 제거한다.
지난 일정 개인 배정, 비공식 카드/포인트/방문 이력, 식당 배정은 보존한다.
데이터 정리는 설치 마이그레이션에 넣지 않는다. 운영에는 적용하지 않는다.

백업의 calendar_events와 event_informal_assignments가 복구 자료다. 롤백 SQL은
스키마만 복구하며 삭제된 개인 배정을 자동으로 되살리지 않는다. 전체 복원 리허설은
운영 전 별도 필요하다. 비공식만 변경한 알림의 변경 감지는 기존 카드 알림과 별도 후속이다.

## 리뷰 후 보호 조치

`20260930_1400_guard_team_service_sharing.sql`은 개인 배정이 한 건이라도 남아 있으면
공유를 거부한다. 공유 RPC에는 더 이상 개인 배정 DELETE가 없다. 자동 흡수/삭제는 하지
않으며 별도 전환 작업을 승인받아야 한다. UI도 기존 개인 배정 건수와 차단 이유를 표시한다.
권한 검사 후 개인 배정 표를 SHARE 잠금하여 검사 도중의 레거시 쓰기를 직렬화한다.
새 팀 공유끼리는 이 잠금이 호환되지만 옛 개인 배정 쓰기는 트랜잭션 종료까지 기다린다.

보관/삭제/자식 포인트로 바뀐 선택과 사라진 구역 카드는 팀 편집 화면에 이름/ID와
선택 해제 버튼으로 남긴다. 사용자가 해제해야 공유된다. RPC 역시 ID를 포함한 오류로
재검증한다. 이 보안 수정만 되돌려 취약한 RPC를 복구하는 단독 롤백은 제공하지 않는다.
전체 기능 롤백 순서는 informal → scope이며 각 파일은 선행 조건을 검사한다.

합성 자료로 기존 18건 삭제·보관 자산 거부·역순 롤백의 깨진 참조를 DB에서 재현했고
전부 롤백했다. 수정 후 개인 18건/일정 원본 보존, 명시적 선택 해제 후 공유 성공,
역순 거부/정순 성공을 검증했다. 방어 세 개를 각각 무력화했을 때 회귀 검사가 실패했다.
운영 자료 복제나 삭제는 하지 않았다.

보완 후 전체 1016개 시험 및 lint/build 통과. 실제 데모 브라우저에서도 보관 자산의
ID 표시/선택 해제/나머지 자산 공유와 과거 개인 18건의 안내/공유 차단/보존을 확인했다.
브라우저 확인용 일정·자산·세션은 끝난 뒤 제거했다. 변경 직전 전체 백업은
`/tmp/field-map-demo-backups/before-team-guards.dump`에 별도로 보존했다.
새 회중 전체 설치 및 전체 백업 복원 리허설은 이번 부분 검증과 별개로 남아 있다.

## 참가자 제외 경로 검증 (운영 적용 차단)

데모에서 `_REPRO_team_participant_removal.sql`을 단일 트랜잭션으로 실행했다.
새 팀 비공식 배정을 만든 합성 일정에서 기존 `removeParticipantFromEvent`의
DELETE 순서를 anon 세션으로 재현했다. 배정 DELETE는 RLS로 0건 처리되지만
참가자 DELETE는 1건 처리되어, 참가자 없는 `event_card_assignments` 행이 남는다.
모든 합성 자료는 ROLLBACK했다. 이 문제는 아직 수정하지 않았으며 운영 적용을 막는다.

후속 수정은 정책 완화가 아니라 권한을 검증하는 원자적 참가 취소 RPC로 진행한다.
본인 신청 취소와 관리자 제외를 함께 조사하고, 다른 팀원 배정 및 방문 기록 보존,
마지막 팀원 제외 시 메타 정리, 공유시각 충돌 방어까지 검증해야 한다.

별도 정리로 AssignmentEditor의 allCards를 필수화하고 필터 목록 폴백을 제거했다.
회귀 시험은 cards를 빈 배열로, allCards를 실제 카드 목록으로 전달한다.
검사를 cards로 일부러 바꾸면 3개 중 2개가 실패하는 것을 확인한 뒤 원복했다.
롤백 주석의 개인 배정 삭제 설명은 1400 보호 조치 이전 전환에만 해당하도록 한정했다.
