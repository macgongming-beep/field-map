# 인도자의 내 집단·전체 구역 탐색

상태: 승인, 데모 검증. 운영 미적용.
날짜: 2026-11-21

## 결정

- 인도자의 PC·모바일 구역 목록은 다른 집단 선택칸 대신 `집단명 집단 구역 / 전체 구역`을 쓴다. 목록·지도 버튼은 유지한다.
- 소속 집단을 기본으로 연다. 소속이 없으면 전체를 열고 내 집단 버튼을 비활성화한다. 공동 담당 카드는 기존 코드 포함 판정을 유지한다.
- 인도자 지도 버튼은 내 집단과 전체만 전환한다. 관리자·개발자의 집단 선택은 유지한다. 권한이나 저장 계약을 변경한 것은 아니다.
- 집단 목록에서 지도에 들어가면 해당 집단 보기가 켜지고 카드 경계선을 바로 표시한다. 회중 전체 외곽선은 숨긴다. 전체 보기에서는 전체 외곽선을 복원한다.
- 전체 보기의 모바일 구 단계는 기존 집계를 유지하고, 동 단계부터 카드 경계선을 표시한다. 집단 보기에서는 현재 집단 카드만 표시한다.
- 확대 중에는 화면 주변 25% 여유 범위만 그리고 기존 40개 단위 작업을 유지한다. 탐색 지도에만 경계선 화면 제한 시작을 zoom 13으로 앞당긴다. 다른 지도 기본값은 15다.
- 드래그·GPS 이동·확대 뒤 경계선만 갱신할 수 있게 한다. 필터 변경으로 직접 맞춘 카메라를 다시 맞추지 않으며 GPS 배율 계약도 유지한다.
- 이동 후 경계선 갱신은 공용 `MapCanvas` 변경이므로 배정 지도에도 적용된다. 배정 지도의 화면 제한 기본값 15는 유지하며, 범위 밖에서 새로 들어온 경계선을 갱신할 뿐 배정·카메라 값을 바꾸지 않는다.
- 일반 탐색 지도의 모바일 동 단계 경계선 표시와 PC·모바일 zoom 13 화면 제한은 집단 기능 설정과 무관하게 적용된다. 기존 자료 접근 범위와 일반 성원의 제한을 넓히지는 않는다.
- URL에 `groupView=all`을 남겨 전체로 전환한 뒤 다시 열어도 기억한 집단 코드 때문에 필터가 켜지지 않게 한다. 주소 검색의 필터 밖 결과 공개 예외는 유지한다.

## 검증

- 전체 시험 2,915개 통과. lint, TypeScript 통과.
- 분리 복사본 변이 6개 모두 검출: 인도자 소속 코드 무시, 전체 외곽선 전환 제거, 동 경계선 숨김 복원, 화면 제한을 15로 복원, 이동 후 경계선 갱신 제거, 목록에서 타 집단 코드 허용. 각각 새 시험 1개 실패.
- 실제 Naver SDK + WebKit, 가상 구역 609개 / 본인 집단 118개. 목록·지도 320/390/430px 및 390px 아주 큰 글씨 검사. 가로 넘침·제목/버튼 겹침 없음. 지도 헤더 일반 91px, 아주 큰 글씨 113.5px.
- 집단/전체 전환 후 zoom 14 유지. 화면 오류 0개. 가상 자료를 사용하는 화면 탐색에서 Supabase 요청 0건. 저장은 금지한 fixture다.
- 609개 경계선 시험은 화면 안 1개만 우선 표시하고, 드래그와 프로그램 이동 후 새 범위 경계선을 표시하며, 축소 시 제한을 풀어 다시 나타나는지 확인한다.
- 조회·SQL·권한·배정 저장 파일 변경 없음. 서버 사용량 절감이나 실제 로딩 시간 단축을 측정한 변경은 아니다. 이미 받은 자료의 표시만 바꾸므로 추가 데이터 조회 경로는 없다. 지도 타일 요청량은 실제 이동 범위에 따라 달라질 수 있다.

## 검증 범위와 배포

- 화면 fixture는 데모 도메인에서 로컬 빌드 응답을 대신 제공했다. Naver 키가 localhost를 거절해 첫 시도는 실패했고, 실제 허용 도메인으로 재검사하여 통과했다. 운영 데이터나 데모 업무 자료는 수정하지 않았다.
- 로컬 기록: `scratch/leader-browse-tests.json`, `scratch/leader-browse-mutations.json`, `scratch/leader-browse-visual.json` 및 스크린샷.
- 0150에서 맞춘 운영과 동일한 기능 설정으로 데모를 빌드한다. DB·푸시·지도 키는 데모 전용이며 운영 배포/환경변수는 변경하지 않는다.
- 실물 아이폰에서 `내 집단 목록 → 지도 → 전체 전환 → 확대 → 뒤로` 확인은 사용자 확인으로 남긴다.

## 후속: 선택한 지역을 지도 제목에 표시

- 중국어의 `{group} 집단 구역`은 기존 합성 사전을 통해 `{group}小组地区`로 번역된다. 사전을 새로 바꾸지 않고 실제 번역 경로로 `新葛小组地区`를 검증했다.
- 모바일 지도 제목은 배정 진입 제목, 선택 카드, 선택 동, 선택 구, 집단 선택/집단명, 기본 `구역-지도` 순으로 표시한다. 비공식 장소 제목은 기존 경로를 유지한다.
- 구/동을 선택한 동안 제목에 그 이름을 보여 주고, 뒤로 가면 단계에 맞게 복귀한다. 지역명 번역 설정도 기존 `placeLabel`을 사용한다. 집단 필터·통계·경계선·카메라·저장/조회는 바꾸지 않는다.
- 전체 시험 2,917개 및 lint 통과. 분리 복사본에서 구 제목 제거(2개 실패), 동 제목 제거(2개 실패), 중국어 집단 번역 제거(1개 실패)를 확인했다.
- WebKit + 실제 Naver SDK에서 집단 → 기흥구 → 중동 → 뒤로 → 집단 → 전체 제목 전환 확인. 가상 자료를 사용했고 추가 DB 요청/화면 오류 0개. 기록은 `scratch/leader-heading-*.json`, `scratch/leader-heading-dong.png`.

## 클로드 리뷰 후 시험 보강

- 클로드가 검토한 범위는 `7e3b177` / 기록 `7c59446`까지다. 지도 헤더 후속 `0a3bb20`은 해당 리뷰에 포함되지 않았다.
- 이번 보강은 시험·문서만 변경한다. 앱 코드·DB·환경변수 변경 및 재배포 없음.
- PC 인도자가 타 집단의 `initialGroupCode`로 진입해도 본인 집단 건물만 보이고, 전체로 전환하면 양쪽을 보는 시험을 추가했다.
- 전체 전환 뒤 본인 집단 구역 검색과 검색 해제에서 `groupView=all` 및 전체 필터 상태가 유지되는지 검사한다.
- 실제 `DesktopMap`이 지도에 넘기는 외곽선 표시, zoom 13, 집단/전체 경계선 후보를 검사한다.
- 모바일 구역 목록의 구 단계 경로에서 집단명/전체 범위 표시를 검사한다. 최상위 전환 버튼만 확인하는 시험이 아니다.
- 최초 외곽선 생성 옵션의 `map`이 null인지 검사한다. 후속 effect가 가려 버린 뒤의 상태만 보는 기존 시험 공백도 보강했다. 이는 생성 시 붙이지 않는 계약 검사이지 실물 화면의 프레임 측정은 아니다.
- 관련 5파일 56개와 전체 2,922개 통과, lint·TypeScript 통과. 분리 복사본에서 위 보호를 제거하는 변이 6개를 실행했으며 각각 시험 1개가 실패했다.
- 기록: `scratch/leader-review-mutations.json`, `scratch/leader-review-tests.json`. 실물 아이폰 및 실제 로그인부터의 요청량·타일량·시간 미측정 범위는 그대로다.
