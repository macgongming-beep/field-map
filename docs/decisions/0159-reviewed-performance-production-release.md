## 반영 범위

0153~0158의 지도 축소 표시 재사용, 봉사자 홈 코드 선로딩, 개인 구역 ID 재사용,
경량 화면 조회, 홈 진행률 제거와 제안 지연 조회, 나의 봉사 복구/일정 읽기 병렬화를 반영했다.
사용자가 최신 데모의 홈/나의 봉사/지도 이동에 이상 없음을 확인한 뒤 운영 적용을 승인했다.

`VITE_RECIPIENT_DISCOVERY_REUSE_ENABLED=true`와 `VITE_ROUTE_LIGHTWEIGHT_ENABLED=true`를

두 설정을 더한 운영 기능 설정은 검증한 데모 프로필과 일치했다.

DB, SQL, 의존성/잠금 파일, 배정 저장 및 권한은 변경하지 않았다. 데모 자료를 운영으로
옮기지 않았다. 0152와 같은 방식으로 실제 운영 소스의 후손인 검증된 정확한 커밋을
격리 추출해 배포했다. main은 변경하지 않았으며 다음 main 기반 배포에 이 변경을 포함해야 한다.

## 검증

1. 통합 직전 분리 복사본에서 전체 294파일 2,977개 시험, TypeScript, lint 통과.

3. 운영 활성 배포와 소스, 자동 배포 OFF, 기존 환경설정을 먼저 확인했다.
4. 운영 설정 두 개만 추가하고 나머지 설정 및 활성 배포가 그대로임을 확인했다.
5. 격리 소스를 운영 설정으로 `--prod --skip-domain` 배포 1회. 클라우드 TypeScript/Vite/PWA 빌드 통과.
6. 연결 전 새 배포의 HTML/SW/매니페스트/JS/CSS 25개 검사. 운영 DB 주소 포함, 데모 DB 주소 미포함 확인.
7. 운영 주소가 아직 이전 배포이고 환경설정이 예상과 일치함을 재확인한 뒤 같은 배포를 promote했다.
8. 운영 주소의 파일 25개 해시 일치, 활성 배포 ID, 환경설정, 자동 배포 OFF 유지 확인.
9. WebKit 390px와 Chromium 1440px에서 홈/캘린더/구역/지도/배정 주소의 로그인 화면 진입 확인.
   가로 넘침, 페이지 오류, 정적 파일 실패, DB 쓰기 요청 모두 0건이다.

마지막 화면 검사는 로그인 전 공개 진입 검사다. 운영 로그인 후 업무 흐름이나 실물 아이폰
업데이트 완료를 검증했다고 주장하지 않는다. 운영 실측 속도/하루 사용량도 이번 배포에서 재지 않았다.
기존 큰 청크 및 inlineDynamicImports 경고는 남아 있으며 빌드는 성공했다.
