# 모바일 집단 지도 헤더 축소

- 상태: 데모 적용 완료, 운영 미적용. 배치 결정은 [0147](0147-event-group-territory-map.md)로 대체됨
- 결정일: 2026-11-20
- 선행: 0141 집단 구역, 0145 운영 전환

## 변경

모바일 구역 지도에서 별도 줄을 차지하던 집단 선택을 전체/주택/상가 통계와
같은 줄로 옮긴다. 제목과 지도/중국어 필터/검색 아이콘은 기존 위치를 유지한다.
선택칸은 테두리 없는 80px 기본 폭의 네이티브 선택 메뉴로 표시한다.
긴 이름은 선택칸 안에서 줄이고 메뉴를 열면 전체 이름을 볼 수 있다.
큰 글씨나 긴 숫자는 통계를 줄바꿈하여 선택칸과 겹치지 않도록 한다.

집단 선택값, URL, 필터 계산, 지도 위치, GPS, 권한, 저장, DB와 조회 경로는
수정하지 않았다. PC의 선택칸 스타일도 바꾸지 않았다. 추가 요청은 없다.

## 검증

- 지도/집단 UI 관련 시험 5개 파일, 71개 통과. lint와 빌드 통과.
- 새 관리자/인도자 시험은 통계와 집단 선택이 같은 컨테이너 안에 있는지,
  집단 변경 후 URL/핀 범위, 전체 보기 복귀를 확인한다.
- 선택칸을 이전의 별도 줄로 되돌리는 변이에서 새 시험 2개가 실패했다.
- WebKit 320/390/430px와 390px 아주 큰 글씨에서 가로 넘침, 제목/도구 및
  통계/선택칸 겹침 없음. 범례가 헤더 아래로 이동하는 것도 확인했다.
- 보통 글씨 헤더: 142px -> 103px (39px, 약 27% 감소).
- 390px 아주 큰 글씨: 177.25px -> 148.5px. 통계 줄바꿈을 허용한다.
- 높이는 브라우저 상태 표시줄을 제외한 측정값이다.

실제 데모의 변경 전 화면과 새 산출물을 같은 데모 주소로 읽힌 화면을 비교했다.
데모 로그인 외에 구역/배정 쓰기는 하지 않았다. 최초 localhost 검사에서는
지도 제공자의 주소 인증 실패가 발생했으므로 그 실행은 지도 검증 근거에서
제외했다. 허용된 데모 주소에서 새 정적 파일을 읽힌 재검증은 지도 표시와
집단 변경을 포함하여 페이지 오류 없이 통과했다.

- 비교 기록: `scratch/compact-map-before.json`, `scratch/compact-map-after.json`
- 검증 산출물: `scratch/group-territory-release-compactheader2`
- 데모 배포는 0138의 단일 배포 경로만 사용한다. 운영 배포/DB 변경은 하지 않는다.
