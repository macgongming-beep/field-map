# 일정 메뉴 문구와 시간 설정 아이콘

- 상태: 데모 검증, 운영 미적용
- 결정일: 2026-11-18
- 기준: `5342c84`

## 요청과 확인

일정 추가/수정의 자주 쓰는 시간 옆 톱니바퀴가 기존 앱과 다르게 보인다는 요청이다.
회중 봉사의 수정/삭제가 보이지 않는다는 후속 질문은 사용자가 인도자 계정으로
확인했기 때문이라고 확인했다. 권한 오류가 아니므로 권한은 변경하지 않는다.
회중 봉사의 편집/삭제와 집단 봉사의 일정 수정/일정 삭제 문구 차이만 통일한다.

## 변경

- 문자 톱니바퀴를 MobileMap 등의 기존 수정 아이콘과 같은 선형 연필로 교체한다.
  18px, currentColor, 1.8px 선이며 버튼 32px 크기는 유지한다.
  시간 설정 툴팁, 접근성 이름, 펼침 상태, 열기/닫기/저장 동작은 그대로다.
- 모바일/PC 회중 봉사 메뉴를 `일정 수정` / `일정 삭제`로 맞춘다.
  집단 봉사의 기존 문구와 중국어/영어 번역을 그대로 사용한다.
- 관리자/개발자의 일정 수정·삭제 권한과 인도자의 배정 권한을 바꾸지 않는다.
  조회, 저장, 삭제 확인, 반복 일정 범위 선택, 알림, DB 변경은 없다.

## 검증

- 관련 5파일 44개 시험 통과: 아이콘, 시간 설정 편집/저장/실패/취소,
  회중 관리자/개발자 메뉴 및 인도자/봉사자 메뉴 차단, 편집 닫기 복귀,
  기존 집단 메뉴 동작과 PC 레이아웃/연락처 시험.
- 변이로 문자 톱니바퀴와 회중의 옛 편집 문구를 복구하면 새 시험 3개가 실패한다.
  변이 원복 후 44개 재통과. 전체 2,597개(266파일)와 lint 통과.
- 운영은 변경하지 않는다. 데모에서도 실제 일정 수정/삭제/시간 설정 저장을
  실행하지 않고 화면과 열기/닫기만 확인한다.
