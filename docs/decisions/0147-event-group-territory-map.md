# 집단 일정의 구역 범위와 지도 선택

- 상태: 운영 적용 완료 ([0149](0149-reviewed-group-map-production-release.md))
- 결정일: 2026-11-20
- 선행: 0141 집단 구역, 0145 운영 전환, 0146 모바일 헤더

## 결정

집단 일정에서 팀별 구역을 배분할 때에는 신청 화면에서 선택한 일정의
`targetGroups` 코드에 연결된 구역만 후보로 표시한다. 배정하는 인도자의
소속으로 범위를 정하지 않는다. 공동 담당 구역은 각 담당 집단에서 보인다.
옛 연합 일정에 코드가 여러 개 있으면 해당 집단들의 합집합이다.
집단 코드가 없거나 담당 구역이 없으면 빈 목록이며 전체로 넓히지 않는다.

제목은 집단 이름과 `구역 배분`을 함께 표시한다. 주택/상가 필터, 구역
지도와 목록은 모두 같은 후보를 쓴다. 비공식과 식당은 기존 전체 자료를
유지하며, 회중 일정과 기능 OFF의 후보 범위는 바꾸지 않는다.

이것은 배정 화면의 후보 제한이다. 서버 권한이나 RLS를 새 집단 단위로
제한한 것이 아니다. 기존 인도자/관리자 배정 권한, RPC, 리비전 검사는 유지한다.

이미 저장된 범위 밖 구역을 초안에서 자동 삭제하지 않는다. 기존 선택 문제
안내에 이름을 표시하고 사용자가 직접 해제하기 전에는 다시 공유하지 못하게
한다. 서버에 저장된 배정은 사용자가 공유하기 전까지 그대로다.

집단 담당 관리에는 지도/목록 전환을 추가한다. 지도에서 구역선을 눌러 고른
구역을 기존 추가/해제 동작으로 저장한다. 공동 담당의 다른 집단은 해제하지
않는다. 지도와 목록의 선택은 공유하고, 집단/전체 탭을 바꿀 때는 초기화한다.
검색으로 숨겨진 구역의 늦은 클릭, 저장 중 클릭, 읽기 전용 클릭은 무시한다.
경계선 없는 구역은 수를 표시하고 목록으로 돌아가 선택할 수 있게 한다.

## 헤더

0146의 통계 옆 선택칸 배치는 이 기록으로 대체한다. 선택칸은 별도 줄이나
통계 옆 공간을 만들지 않고 원래 제목 자리를 쓴다. 필터 OFF에는 기존 제목,
ON에는 집단 선택칸을 표시한다. 긴 이름은 한 줄 안에서 줄인다.
배정 지도도 긴 팀원 이름 때문에 헤더 높이가 늘지 않도록 한 줄로 표시한다.
전체 팀원 이름은 팀 구성 화면과 기존 title 속성에 남는다.

## 조회와 기존 동작

- DB, 마이그레이션, 조회 API, 권한, 저장 방식 변경 없음.
- 관리 지도는 이미 읽은 구역/경계선을 이용한다. 이를 위해 전체 건물 본문을
  새로 읽지 않는다. 지도 타일/SDK 통신은 지도 사용에 따라 발생한다.
- 기존 줌 기억과 GPS 동작은 변경하지 않는다. 관리 화면에서 집단을 명시적으로
  바꾸면 새 집단으로 첫 화면을 맞추며, 같은 집단 지도/목록 왕복은 위치를 유지한다.
- 자동 시험은 이벤트 집단과 인도자 소속이 다른 경우, 공동 담당, 빈 범위,
  회중 유지, 비공식/식당 유지, 기존 초안 보존과 명시적 해제를 확인한다.

## 검증

- 관련 시험 22개 파일 149개, 전체 시험 291개 파일 2,901개 통과.
- 타입 검사/빌드, lint, diff 공백 검사 통과.
- 변이: 이벤트 후보 필터 제거 -> 3개 실패, 범위 밖 경계 클릭 방어 제거 ->
  1개 실패. 관리 지도 검색 밖 클릭 방어는 처음에는 기존 시험을 통과했으나,
  검색을 지운 뒤에도 선택이 없어야 한다는 시험을 보강하여 1개 실패로 검출했다.
- WebKit 320/390/430px, 390px 아주 큰 글씨: ON/OFF 헤더 높이 동일.
  보통 91px, 아주 큰 글씨 113.5px. 상태 표시줄 제외. 0146 대비 각각
  12px, 35px 감소. 제목/도구 겹침과 가로 넘침 없음.
  긴 집단 이름을 표시해도 높이 동일. 배정 지도에서 긴 팀원 이름을 넣어도
  헤더 높이가 유지되는 것을 같은 브라우저 검사에서 확인했다.
- WebKit 390px와 Chromium 1440px: 실제 지도와 구역선 표시, 구역선 클릭,
  목록 왕복 선택 유지, 이벤트 집단 제목과 제한된 목록 확인.
- 관리 지도/목록 전환 구간의 추가 REST 요청은 두 브라우저 모두 0건.
  지도 타일 전송량이 0이라는 뜻은 아니다.
- 브라우저 검증은 데모 주소에서 새 정적 산출물을 읽혀 실행했다. 로그인 외
  업무 자료 쓰기는 차단했으며 실제 공유/집단 담당 저장은 실행하지 않았다.
  저장 인자/공동 담당 보존은 자동 시험과 기존 저장 경로로 검증했다.
- 첫 브라우저 검사에서 새 지도 캔버스 높이가 0인 문제를 발견해 전용 높이
  규칙을 추가했다. 이후 실패 둘은 검사 도구가 지도 도구 아이콘까지 구역선으로
  고른 것, 로딩 제목을 완료 제목으로 읽은 것으로 수정했다. 실패 실행을 최종
  성공 근거에 포함하지 않는다.
- 도구: `scripts/smokeGroupEventMap.mjs`, 기록: `scratch/event-group-map-final.json`.
