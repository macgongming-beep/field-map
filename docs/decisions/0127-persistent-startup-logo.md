# 최초 로고 요소를 첫 화면까지 유지

- 상태: 데모 검증, 운영 미적용
- 결정일: 2026-11-18
- 관련: 0124, 0126

## 배경과 확인 범위

사용자는 설치한 아이폰 데모에서 로고가 잠깐 사라졌다 다시 보인다고 설명했다.
0126은 최초 실행 이후의 로고 재등장을 막았지만 시작 중 요소 교체까지 막지는 않았다.
기존 프레임 검사는 로고의 존재만 확인했으므로 같은 모양의 새 요소를 구분하지 못했다.

추가한 DOM 요소 식별 검사로 기존 배포를 실행하니 자동 로그인 중 서로 다른 로고
요소가 4개 만들어졌다. 이는 재현한 앱 내부 교체이며, 실제 아이폰 화면 녹화로
깜빡임 원인이 이것뿐이라고 확인한 것은 아니다. OS 시작 화면 설정은 변경하지 않는다.

## 구현

- HTML의 #root 안에 #app-startup과 #app-content를 나란히 둔다.
  React는 #app-content에만 붙여 부트 SVG를 지우지 않는다.
- 초기 AppLoading은 기존 로고 아래 #app-startup-status에 상태/복구 UI만 포털한다.
  포털도 #root 내부여서 사용자별 글씨 확대가 복구 버튼/안내에 적용된다.
- 인증 복원, keyed AppSession 교체, 자료 대기, lazy 화면 대기 동안 원래 SVG가
  연결된 채 유지된다. 로고 크기는 확대 설정이 복원돼도 화면상 64px를 유지한다.
- 첫 로그인/앱 화면이 실제 커밋될 때 AppScreenReady가 부트 요소를 제거한다.
  오류 경계, 공유 보고서, 데모 미리보기, 자료 범위 오류 경로도 해제하여 가리지 않는다.
- 최초 화면 이후 로고 없는 대기라는 0126 계약은 유지한다.
- 최소 표시 시간/페이드/추가 타이머/조회는 없다. 기존 12초 지연 안내와 수동 복구,
  실패 안내, 로그인/자료 준비 조건, 권한/DB/배정 코드는 변경하지 않는다.

## 검증

- 전체 268파일, 2616시험 통과. lint, TypeScript/데모 빌드 통과.
- 실제 index.html을 설치한 테스트 DOM에서 원래 로고 객체의 동일성/연결과
  keyed 단계 교체, Suspense 보류/해제, 오류/12초/복구 실패, 콜백 없는 해제를 확인한다.
- 변이: 기존 슬롯 사용을 끄면 새 시험 2개가 실패한다(중복 로고와 복구 위치).
- 기존 배포에 강화된 브라우저 검사를 실행하면 logoElements=4로 실패했다.
  원본 실행 이름: persistent-logo-before. 실제 아이폰 화면 검사로 설명하지 않는다.
- 새 빌드 WebKit/Chromium 390/320/1365px에서 로고 요소 1개, 프레임상 중간 공백 0,
  로그인 후 재등장 0, 부트/React 위치 일치, 오류/12초 복구 안내를 확인한다.
  Chromium의 320px/150% 확대에서도 로고의 실제 크기 64px를 확인한다.
- 새 이미지/글꼴 요청은 없다. 원본: scratch/startup-persistent-logo-{webkit,chromium}-ui.json.
- 실제 설치형 아이폰에서 사용자의 재확인은 남아 있다. 실제 안드로이드 기기도 미검증이다.

## 사용량 확인

REST 120ms 지연, 세 역할 각 1회 검사. 직전 0126의 같은 설정/도구 기록과 대조했다.
교차 반복 측정이 아니므로 속도 개선의 통계 근거로 사용하지 않는다.

| 역할 | 앱 재실행 요청 | 캘린더 | 홈 복귀 | 이번 홈 준비 |
| --- | --- | --- | --- | --- |
| 봉사자 | 39 → 39 | 17 → 17 | 3 → 3 | 2312ms |
| 인도자 | 29 → 29 | 6 → 6 | 3 → 3 | 1188ms |
| 실제 관리자 | 29 → 29 | 6 → 6 | 3 → 3 | 1235ms |

9구간의 요청 대상 목록도 같다. 응답 원문은 관리자 앱 재실행의 app_users가 1바이트
작아진 것 외에는 같다. 정적 index.html+메인 JS의 gzip 합은 14601→14781B(+180B)다.
따라서 데이터 조회 증가/추가 파일 요청은 없지만 다운로드 크기가 완전히 같지는 않다.
원본: scratch/speed-startup-once-after.json, scratch/speed-persistent-logo-after.json.
