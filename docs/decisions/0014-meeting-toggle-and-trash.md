# 모임 정리: 수동 홈 표시와 모음 휴지통

- 상태: 운영 반영 (2026-10-02)
- 결정일: 2026-10-02
- 대체: 0013의 날짜 기반 홈 노출 및 복원 없는 모음 보관

## 결정

- 홈 표시는 home_enabled만 사용한다. 시작일/종료일/홈 표시 종료일 입력과 홈 날짜 표시는 제거한다.
- 기존 날짜 컬럼은 구버전 저장 RPC 호환과 데이터 보존을 위해 유지하되 노출 판단에 사용하지 않는다.
- OFF인 모음도 관리자 설정의 내용 보기에서 목록과 본문을 확인할 수 있다. OFF는 접근 제한이 아니다.
- 모음 삭제는 archived_at을 설정하는 휴지통 이동이다. 원문과 개별 글 보관 상태를 변경하지 않는다.
- 휴지통은 관리자/개발자만 조회하며 복원 또는 완전 삭제할 수 있다. 복원은 항상 홈 표시 OFF다.
- 완전 삭제는 휴지통에 있는 모음과 그 모음의 모든 글만 삭제한다. 일정, 방문 기록, 다른 모음은 보존한다.
- 완전 삭제는 대상 이름과 모든 글 삭제/복구 불가 안내를 확인한 후 실행한다.
- 서버에서 역할, 모음 상태, updated_at 충돌을 검사한다. 글 저장과 휴지통 작업은 테이블 잠금으로 직렬화한다.
- 일반 사용자/인도자는 휴지통 모음의 글을 직접 URL로도 읽을 수 없도록 부모 상태를 RLS에서 확인한다.

## 검증

- 데모 백업 후 SQL 단일 트랜잭션으로 시험한다. 시험 데이터는 ROLLBACK한다.
- 사용자/인도자 쓰기 거부, 휴지통 RLS, 원문 보존, 복원 OFF, 활성 모음 완전 삭제 거부, 충돌, 일정 보존을 검사한다.
- 관리자 검사 및 충돌 검사를 제거한 변형에서 시험 실패를 확인한다.
- 운영 반영은 별도 승인 대상이다. 완전 삭제한 데이터는 롤백 SQL로 복구되지 않는다.

## 운영 전환 (2026-10-02)

- 사용자 승인으로 운영 전환. 삭제된 데모 주제는 복원하거나 이전하지 않는다.
- 운영 최신 main을 병합해 기존 사용량 절감 변경을 보존했다. 전체 1,141개 테스트 및 lint/build 통과.
- 전체 DB custom dump 생성 및 pg_restore 읽기 검증 완료. 별도 DB 복원 리허설은 수행하지 않았다.
- 1500/0100/1200 모임 마이그레이션과 콘텐츠 이전을 운영에서 단일 트랜잭션으로 리허설 후 ROLLBACK, 이후 동일 절차로 적용했다.
- 현재 활성 주제 1개와 한국어/중국어 글 3개만 이전했다. 이름·본문·목록 제목·발췌·날짜·표시 설정은 양방향 EXCEPT로 원본과 일치 확인.
- 데모 일정/사용자 ID는 운영 ID와 연결하지 않는다. event_id/author_user_id는 NULL, 장소/인도자 데모 스냅샷은 빈 값으로 이전한다. 운영 캘린더와 봉사 기록은 변경하지 않는다.
- 홈 표시는 데모와 동일하게 ON. 영구 삭제된 데모 주제 및 휴지통은 이전 대상에서 제외한다.
- 운영 기능 플래그는 DB 적용 후 설정했다. 첫 CLI 입력에 개행이 포함되어 정확한 `true` 비교에 실패하는 것을 환경값 검증에서 발견, 개행 없는 값으로 정정하고 재배포한다.
- 기존 실시간 동기화/팀 봉사 플래그는 정확한 `true`를 유지한다. 익명 REST 조회는 두 신규 표 모두 빈 목록이며 직접 쓰기 권한이 없다.
- 앱 배포는 최신 운영 main을 병합한 `7ee83b1`과 이 기록 변경만 포함한다. 실제 운영 별칭의 정적 자산에서 운영 DB 참조·주제 관리·휴지통·설정 경로를 재확인한다.
