## 배경

- 사용자: 휴대폰에서 지도를 움직일 때 끊긴다. 안드로이드가 특히 심하다.
- 측정(운영 규모 47배, CPU 6배, 실제 터치 입력)
  - 인도자 구역 지도 `/map`: 두 손가락 축소 때 약 250ms 멈춤, 축소한 상태로 끌 때 약 85ms 멈춤
  - 인도자 배정 지도와 봉사자 배정 지도는 끊김 0
  - 그냥 끌기는 어디서나 끊김 0
- 원인(프로필, 압축 안 한 빌드)
  - 축소하면 구역선이 수백 개 새로 생긴다. 기본 모양으로 만든 뒤 `updatePolygonStyles`가 전부 `setOptions({ ..., map })`으로 다시 칠했다.
    - 네이버 SDK는 같은 지도를 넘겨도 지도에서 뗐다가 다시 붙인다(`_unbindMap`·`_bindMap`). 이것이 267ms였다.
  - 끌면 화면 밖으로 나간 구역선을 `setMap(null)`로 떼고(73ms), 돌아오면 새로 만들었다.

## 결정

1. 구역선을 처음부터 최종 모양(선택·강조·팀색·클릭 가능)으로 만든다.
   - 만든 모양을 기록해 두어 바로 뒤의 다시 칠하기를 건너뛴다.
   - 다시 칠할 때도 `map`을 넘기지 않는다. 보이기·숨기기는 `setVisible`로 따로 한다(그리는 중인 카드 포함).
2. 화면 밖으로 나간 구역선은 떼지 않고 숨겨 둔다. 돌아오면 다시 보이기만 한다.
   - 숨겨 둔 사이 모양(좌표)이 바뀌었으면 새로 만든다.
   - 숨겨 둔 것이 300개를 넘으면 오래된 것부터 정말로 뗀다.
   - 필터·삭제로 구역선 자체가 없어지면 예전처럼 뗀다.
   - 숨긴 구역선에는 카드 이름표를 만들지 않는다.
- 보이는 모습은 바꾸지 않았다. 점선·반투명 채움을 줄이는 방안(GPU 부담)은 사용자 결정으로 남긴다.
