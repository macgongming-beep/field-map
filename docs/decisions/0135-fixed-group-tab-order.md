# 집단 탭 순서는 고정하고 내 집단만 선택

- 결정일: 2026-11-19
- 상태: 구현, 배포 검증 중
- 대체: 0134의 내 집단 첫 탭 정렬만 대체

사용자 요청에 따라 집단 탭 위치는 모든 계정과 모바일/PC에서 집단 목록 순서대로 유지한다.
내 집단을 앞에 옮기지 않고 진입할 때 해당 탭만 선택한다. 수동 선택은 재조회 뒤 유지하며,
계정 변경은 새 계정의 소속을 선택한다. 댓글 알림은 해당 집단 선택이 우선한다.
소속이 없거나 해당 시간에 내 집단 일정이 없으면 기존 기본 선택을 유지한다.

개인별 정렬 한 줄만 제거한다. 신청, 권한, 배정, 댓글, 조회와 DB는 변경하지 않는다.
회귀 시험은 모바일/PC 각각 동백 기본 선택, 신갈 수동 선택과 재조회, 처인 댓글 이동,
신갈 소속 계정으로 전환하는 동안 네 집단의 전체 순서가 같은지 확인한다.
수정 전 코드에서는 이 두 시험이 실패하여 잘못된 정렬을 실제로 잡는 것을 확인했다.

집단 봉사 관련 23개 파일 / 152개 시험, lint, TypeScript를 포함한 운영 설정 기반
데모 빌드가 통과했다. 실제 휴대폰 검사는 별도이며 DB/환경변수 변경은 없다.
