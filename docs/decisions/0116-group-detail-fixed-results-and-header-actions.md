# 집단 상세 배정 결과 고정 및 일정 메뉴 위치

- 결정일: 2026-11-18
- 상태: 데모 적용. 운영 변경 금지.
- 관련 기능: 집단 봉사 상세

## 결정

사용자 요청으로 기존의 '공유하면 펼쳐지는 배정 결과'를 대체한다. 공유된 배정 결과는
접기 없이 고정 표시한다. 공유 전 초안, 권한 없는 다른 팀 결과는 계속 숨긴다.
내용이 있을 때만 표시되는 모임 정보의 접기 동작은 변경하지 않는다.

일정 수정·삭제는 신청자 제목 줄에서 제거하고 모바일 상단 헤더의 더보기 메뉴로
이동한다. PC는 기존 헤더 구조를 유지하며 상세 상단 제목 옆에 같은 메뉴를 둔다.
현재 선택한 집단의 일정 ID로 기존 수정·삭제 동작을 호출한다. 관리자 편집 권한이
없거나 해당 콜백이 없으면 메뉴 항목을 표시하지 않는다.

신청자 추가·제외 버튼은 신청자 줄에 유지한다. 배정·신청·댓글·DB 권한은 변경하지
않으며 메뉴 이동으로 수정 범위를 전체 집단으로 넓히지 않는다.

## 검증

- 고정 결과, 초안 및 타 집단 결과 숨김, 모임 정보 접기 유지 회귀 시험.
- 모바일/PC 메뉴 위치, 선택 집단 ID, 권한, 탭 전환·바깥 클릭·Escape 닫기 및 키보드 이동 시험.
- 실제 데모 자료로 화면 및 편집 취소 복귀 확인. 일정 저장·삭제는 실행하지 않는다.
- 로컬 데모 빌드에서 390px WebKit과 1365px Chromium 화면·편집 열기/X 복귀 확인.
  WebKit 첫 검사에서 포인터 선택 직전의 null-focus blur가 메뉴를 닫는 문제를 발견했다.
  명확한 외부 포커스 이동만 닫기로 처리하고 바깥 포인터 닫기는 유지한 뒤 재검증했다.
- 편집 권한을 배정 권한으로 바꾸고 접기 요소를 되살린 변이에서 시험 2개가 실패함을
  확인했다. 정상 코드로 복원했다.
- 화면 및 네트워크 기록: `scratch/nov18-actions-local-*-navigation.json`,
  `scratch/nov18-actions-local-*-schedule-menu.png`, `scratch/nov18-actions-local-*-assignments.png`.
- 전체 자동 시험 2,541개(262개 파일), lint, 데모 설정 빌드 통과.
