## 적용 범위

검토받은 집단 구역 공동 담당, 집단 목록/지도 필터와 화면별 로딩 개선을
기존 main 위에 fast-forward했다. 의존성이나 앱 코드를 이번 배포에서 추가 수정하지 않았다.
운영 설정은 `VITE_GROUP_TERRITORY_ENABLED=true`만 추가했다.
기존 구버전 배정 호환 단계와 다른 환경변수, 자동 배포 차단은 그대로 유지했다.

적용한 SQL은 아래 두 파일이며, 같은 `psql --single-transaction` 실행에 묶었다.

- `20261120_1600_territory_group_assignments.sql`
- `20261120_1700_territory_group_review.sql`

운영 집단 4개와 구역 609개를 사전 확인했다. 구역을 잠근 뒤 트랜잭션 안에서
기존 구역의 모든 열을 비교했으며, 새 수정 번호를 제외한 기존 내용은 동일했다.
초기 집단 연결은 0건, 수정 번호는 모두 0이었다. 기존 개인/일정/팀 배정은
변환하거나 지우지 않았다. 관리자가 실제 집단 담당을 선택해야 한다.

## 배포 중 정정

최초 배포 `dpl_H8AsJkm8VGharEMUAwauqeuYF1nT`에는 CLI 표준입력의 줄바꿈이
설정값에 포함되어 `true\n`으로 저장됐다. 정확한 문자열을 비교하는 기능 설정이므로
이 배포에서는 집단 기능이 켜지지 않았다. 운영 파일 확인 과정에서 발견했다.

CLI의 명시적 값 인자로 `true`를 저장하고, 설정을 다시 내려받아 완전 일치를
검증한 뒤 같은 코드를 한 번 더 배포했다. 최종 배포 파일에서도 줄바꿈 없는
활성 기본값을 확인했다. SQL은 다시 적용하지 않았고 기존 자료 변경도 없었다.
배포 횟수는 이 정정을 포함해 2회다. 향후 활성화 설정은 배포 전에 완전 일치를 확인한다.
