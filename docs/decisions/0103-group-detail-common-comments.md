# 집단 상세: 빈 모임 정보 숨김, 회중 봉사와 같은 댓글창

- 상태: 데모 적용·검증 완료. 운영 미적용
- 결정일: 2026-11-17
- 이전 결정: [0101 댓글 기본 접힘](0101-demo-group-event-comments.md), [0102 조회·알림 보완](0102-demo-comment-review-followup.md)

## 결정

사용자가 회중 봉사와 집단 봉사의 댓글 경험을 통일하도록 요청했다.
집단 댓글의 별도 details/summary와 제목·테두리를 숨기던 CSS를 제거하고,
회중 봉사와 같은 compact `CommentSection`을 기본으로 표시한다.
댓글 제목, 목록, 작성란, 수정/삭제 메뉴는 공통 컴포넌트를 사용한다.
총 개수를 모르는 페이지 조회에서는 읽은 개수를 전체 댓글 수처럼 표시하지 않는다.

선택한 집단에 인도자·장소·메모가 모두 비었고 화상 모임도 아니면 모임 정보 칸을
렌더링하지 않는다. 공백만 있는 값도 비어 있는 것으로 본다. 장소가 없는 현장 모임
설정만으로 빈 칸을 만들지 않는다. 화상 모임이면 기존 접속 정보 조회/오류/미등록
안내를 유지하므로 정보가 없는 것으로 오인해 숨기지 않는다.
내용이 있는 모임 정보의 기존 접기 방식과 공유된 배정 결과의 펼침 방식은 유지한다.

## 조회·권한 계약

- 댓글 기본 접힘 결정만 대체한다. 서버 권한·알림 대상·링크·배정 권한은 변경하지 않는다.
- 상세 진입 및 집단 탭 선택 시 선택한 집단의 최신 20개를 자동으로 읽는다.
  이전의 '접힌 상태에서는 0회' 절감 수치는 더 이상 적용되지 않는다.
- 다른 집단 댓글을 미리 읽거나 모든 집단을 동시에 구독하지 않는다.
- 탭 이동/화면 종료 시 기존 댓글 구독을 해제하고 백그라운드 중 조회를 멈춘다.
- 이전 댓글은 20개씩 수동 조회, 변경 신호는 해당 ID만 조회하는 방식을 유지한다.
- 계정별 초안 격리, 집단별 작성 중 내용, 무효 세션 안내를 유지한다.

## 검증

- 모임 정보 없음/공백/집단 전환, 인도자·장소·메모·화상 설정 각각의 표시 시험.
- 댓글이 처음부터 공통 compact 작성란으로 표시되고 집단 전환 시 이전 내용이
  섞이지 않는지, 알림 초점과 초안을 전달하는지 시험.
- 빈 모임 정보 숨김을 의도적으로 무효화하면 회귀 시험이 실패함을 확인했다.
- 전체 2,590개 시험, lint/build 통과.
- 로컬 화면+데모 DB의 브라우저 검사 34개 통과, JS 실행 오류 0개.
  PC와 320px/125% 글씨 화면을 확인했다. 첫 선택의 댓글 20개 조회는 1회/5,600B였다.
  응답 본문 크기일 뿐 청구 전송량은 아니며, 이전 기본 접힘의 0회 조회와 비교해
  상세를 열기만 하는 경우에도 이 조회가 발생하는 변경임을 기록한다.
- 실제 화면·전송량은 갱신된 `scripts/checkGroupCommentsDemo.mjs`로 확인한다.
  데모 합성 자료의 측정이며 운영 사용량이나 실제 기기 푸시 검증을 대신하지 않는다.
- 배포된 데모에서도 같은 34개 검사 통과, JS 실행 오류 0개.
