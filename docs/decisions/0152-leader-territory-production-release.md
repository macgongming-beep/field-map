1. 배포 직전 운영 활성 배포/소스, Git 자동 배포 OFF 및 기존 기능 설정을 읽기 전용 확인했다.

4. `vercel deploy --prod --skip-domain`으로 배포 1개를 생성했다. 검사하는 동안 운영 주소는 이전 버전을 유지했다.

6. 직전 운영 배포와 환경변수가 그대로인 것을 재확인한 뒤 `vercel promote`로 같은 배포를 운영 주소에 연결했다. 재빌드하지 않았다.
