# 반복 일정 인도자 선택과 PC 메뉴 가시성

- 결정일: 2026-11-19
- 상태: 검증 중

반복 일정 생성 시 인도자를 비워 두던 초기 순번 입력 설계를 변경한다.
반복 종료일을 입력해도 인도자 선택란과 기존 선택을 유지한다. 명시적으로 고른 인도자는
모든 생성 회차에 적용하고, 선택하지 않으면 미지정으로 둔다. 시간대/집단별 반복 ID 분리는 유지한다.
선택한 인도자 신원 검증은 반복 여부와 무관하게 적용한다. 신규 비반복 회중 일정의 필수 조건은 유지한다.

PC 일정 수정 누락 제보는 실제 운영 관리자 화면에서 더보기 → 일정 수정이 열림을 확인했다.
저장/삭제는 하지 않고 취소했다. 버튼이 연한 회색 16px 아이콘/30px 영역이라 찾기 어려웠다.
기존 위치/관리자 권한은 유지하고 아이콘은 20px, 버튼은 40px, 본문 색상으로 변경한다.
더보기 툴팁과 번역된 접근성 이름을 사용한다. 추가 조회나 DB 변경은 없다.
