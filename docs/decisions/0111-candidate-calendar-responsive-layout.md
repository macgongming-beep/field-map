# 후보 캘린더 너비와 긴 제목 보완

- 날짜: 2026-11-17
- 상태: 후보 코드·로컬 화면 검증 완료, 운영 미적용.
- 기준: `740813a`, [0110의 화면 문제](0110-production-settings-candidate-validation.md).
- 범위: PC 상세 패널 잘림과 긴 제목 줄바꿈만 수정. 일정/신청/권한/알림/SQL 계약은 그대로다.

## 변경

- 공통 `.desktop-content`를 바꾸지 않고 `.desktop-content.calendar-layout`에만 유동 열 너비를 적용한다.
- 1494px 미만에서는 캘린더 좌우 여백과 열 간격을 줄인다. 기존 열/여백/사이드바 합계가 1494px였기 때문이다.
- 980~1199px PC에서는 달력 아래에 상세를 놓는다. 1200px 이상에서는 기존 좌우 구성을 유지한다. 980px 미만 모바일 경로는 그대로다.
- 달력 도구 버튼과 상세 헤더는 공간이 부족하면 줄을 바꾼다. 버튼을 숨기거나 글자 크기를 줄이지 않는다.
- PC `.event-hero-title`와 모바일 `.event-detail-title`에 긴 단어 줄바꿈을 적용한다. 글자 크기는 기존 22px/26px 그대로, 자간은 0으로 맞춘다.

## 검증

0110에서 읽은 운영 기능 설정 41개를 그대로 재사용했다. 데모 DB로만 연결하고 DEMO_MODE=false, 새 기능 ON/OFF를 각각 빌드했다. 운영 설정을 다시 변경하거나 DB 준비/호환 전환을 실행하지 않았다. 이번 화면 검사는 조회와 탭/메뉴 이동만 하며 신청·배정 저장이나 DB 권한 변경을 하지 않는다.

- Playwright: ON/OFF 각각 320, 430, 979, 980, 1024, 1199, 1200, 1365, 1440, 1920px, 총 20조합 통과.
- 단순 body scrollWidth가 아니라 달력/상세/도구 버튼의 실제 좌우 좌표를 검사했다. 1200px 경계 전후의 세로/가로 배치와 사이드바 침범 여부도 확인했다.
- 1365px에서 상세 오른쪽은 기존 1446px에서 1341px로 바뀌어 여백 24px 안에 들어온다. ON/OFF 모두 동일하다.
- 980px에서는 상세가 달력 아래에 오고 오른쪽은 956px다. 수정 메뉴와 집단 탭을 실제 클릭해 접근 가능한 것도 확인했다.
- OFF의 실제 상세 제목 요소에 공백 없는 긴 영문/한글/중국어를 넣고 10개 폭에서 글자 범위/부모 폭/다음 요소와 겹침을 검사했다. 320px 125% 확대도 통과했다. 이는 브라우저 DOM의 시험 문구이며 저장된 일정 제목을 바꾸지 않았다.
- 브라우저에 옛 고정 열 너비를 일시 적용하면 1365px 상세 잘림이 다시 발생한다. 긴 제목의 overflow-wrap을 normal로 바꾸면 320/1365px에서 가로 넘침이 발생한다. 해당 역검사 후 정상 스타일로 복구했다.
- 새 CSS/모바일 제목 계약 시험 2개를 추가했다. 인접 화면 시험 포함 4파일/27개, 전체 261파일/2,533개, lint, ON/OFF TypeScript/Vite 빌드 통과. 기존 큰 청크 경고는 남아 있다.
- 브라우저 실행 오류 0건. 0110의 신청/배정/댓글 기능 시험을 이번에 전부 다시 실행한 것으로 주장하지 않는다. 이번 변경은 레이아웃과 제목 스타일뿐이다.
