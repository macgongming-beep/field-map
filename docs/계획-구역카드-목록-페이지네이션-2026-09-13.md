# 구역 카드 목록·페이지네이션 계획

2026-09-13. 구현 전에 목록 정보 우선순위와 일괄 작업 계약을 고정한다.

## 목표

- `유형`은 목록에 복원한다. 카드 성격을 훑는 데 필요한 핵심 정보다.
- `구역선 있음/없음`은 매 행에서 제거하되, 구역선 누락을 찾고 고치는 길은 유지한다.
- 기본 목록은 50개씩 나눠 렌더링하고 필요할 때만 전체를 본다.
- 상세 패널을 열어도 글자가 세로로 쪼개지거나 열끼리 겹치지 않는다.
- 페이지 밖의 카드가 일괄 삭제·병합 대상에 조용히 섞이지 않는다.

## 1. 목록 열 계약

### 상세 패널을 닫았을 때

```
[선택] 카드 | 진행 | 인도자 | 유형 | 중국어 | 정기방문 | 상태 | 작업
```

- 기존 `구역선` 열은 제거한다.
- `유형`은 `주택 7 · 상가 2`처럼 표시한다.
- `전체 9`는 카드의 다른 집계로 알 수 있으므로 유형 칸에서 반복하지 않는다.
- 한 유형만 있으면 `주택 7`처럼 하나만 표시한다.
- 값은 한 줄 말줄임이며, 글자를 세로로 쌓아 공간을 만들지 않는다.

### 상세 패널을 열었을 때

```
[선택] 카드 | 진행 | 인도자 | 유형 | 상태
```

- `중국어`, `정기방문`, `작업`은 상세에서 확인하거나 실행할 수 있으므로 숨긴다.
- 핵심 열에는 각각 고정 최소 너비를 준다.
- 표의 실제 열 너비 합보다 컨테이너가 좁으면 억지로 압축하지 않고 표 내부에서만
  가로 스크롤한다. 페이지 전체에는 가로 스크롤이 생기지 않는다.
- 카드명과 유형은 말줄임 처리하고 전체 값은 `title`로 확인할 수 있게 한다.

## 2. 구역선 상태의 새 위치

구역선은 자동 카드 배정, 구역선 병합, 지도 편집에 필요하지만 평소 카드 목록의
핵심 비교 정보는 아니다. 기능은 유지하고 필요한 순간에 노출한다.

### 고급 필터

```
구역선  [전체] [있음] [없음]
```

- `구역선 없음`을 선택하면 누락 카드만 찾을 수 있다.
- 고급 필터 개수 배지에도 구역선 필터를 포함한다.
- 필터는 `cardBoundaries.some(boundary.cardId === card.id)`를 단일 판정으로 사용한다.

### 상세 패널

- 기존 `구역선 있음/없음` 요약은 유지한다.
- 관리자에게 `구역선 없음`이면 `지도에서 그리기` 명령을 함께 제공한다.
- 명령은 기존 `onOpenCardMap(card.id, true)` 경로를 사용한다.

### 구역선 작업

- 백업·가져오기·병합 화면에서는 현재처럼 구역선 유무를 명시한다.
- 자동 배정과 병합의 기존 경고도 유지한다.
- 따라서 표의 열을 없애도 구역선 자료나 검증 로직은 삭제하지 않는다.

## 3. 페이지네이션 계약

### 기본 동작

- 기본 페이지 크기: `50개`
- 선택지: `25개`, `50개`, `100개`, `전체`
- 페이지 크기는 세션에 저장하되 현재 페이지 번호는 저장하지 않는다.
- 하단에는 `이전`, 주변 페이지 번호, `다음`, `1-50 / 609개`를 표시한다.
- 페이지 번호는 최대 5개만 노출하고 범위 밖은 생략 부호로 표시한다.
- `전체`는 명시적으로 고른 경우에만 사용한다. 609개 전체 렌더링 경로는 남긴다.

### 계산 순서

```
원본 카드
  -> 지역·동·고급 필터
  -> 완료·제외 접기
  -> 페이지 범위 보정
  -> 현재 페이지 카드
```

- 페이지 수와 `1-50 / 609개`의 분모는 완료·제외 접기까지 반영한 실제 목록이다.
- 완료·제외를 펼치거나 접으면 현재 페이지가 범위를 벗어날 때 마지막 유효 페이지로
  보정한다.
- 지역·동·배정·인도자·정기방문·상태·구역선 필터가 바뀌면 1페이지로 이동한다.
- 새 카드가 추가되거나 자료가 실시간으로 바뀌어도 현재 페이지가 유효하면 유지한다.

### 상세 패널과 페이지

- 카드 행을 누르면 현재처럼 상세가 열린다.
- 페이지를 이동했는데 선택 카드가 새 페이지에 없다면 새 페이지의 첫 카드를 선택한다.
- 새 페이지가 비어 있으면 상세 선택을 해제한다.
- 상세를 접었다 다시 열거나 같은 페이지에서 필터 패널만 열 때는 선택을 유지한다.

## 4. 선택·일괄 작업 계약

페이지네이션 뒤의 `보이는 카드`는 **현재 페이지에 실제로 그려진 카드**를 뜻한다.

- 머리글 체크박스는 현재 페이지 카드만 선택·해제한다.
- 페이지를 이동하거나 필터·페이지 크기를 바꾸면 카드 선택을 모두 해제한다.
- 완료·제외 접기 상태를 바꿔 선택 카드가 숨으면 그 선택도 해제한다.
- 삭제·병합·인도자 일괄 적용은 현재 선택 집합만 받는다.
- `전체` 보기일 때만 머리글 체크박스가 필터 결과 전체를 선택한다.
- 선택 버튼에는 `선택 N개`를 표시해 실제 작업 개수와 확인창 개수를 맞춘다.

필터 결과 전체 선택을 별도 기능으로 제공하지 않는다. 609개를 한 번에 다루려면 먼저
`전체` 보기를 고르게 해 작업 범위를 화면에 드러낸다.

## 5. 구현 단위

1. `유형` 열 복원, `구역선` 열 제거, 상세 열림 상태의 열 우선순위와 너비 조정
2. 구역선 고급 필터 및 상세의 `지도에서 그리기` 명령
3. 페이지 상태와 순수 페이지 계산 유틸 추가
4. 렌더 대상을 현재 페이지로 교체하고 선택 계약 변경
5. 페이지 컨트롤 및 `전체` 보기 추가

각 단계를 같은 변경으로 배포하되 시험은 단위별로 나눈다.

## 6. 시험 계약

### 순수 계산 시험

- 609개, 50개씩이면 13페이지다.
- 마지막 페이지는 9개다.
- 필터 결과가 줄어 현재 페이지가 사라지면 마지막 유효 페이지로 보정한다.
- `전체` 보기에서는 필터·접기 이후 카드가 모두 반환된다.
- 완료·제외 접기 전후의 분모와 페이지 수가 실제 렌더 목록과 같다.

### 조립 시험

- 유형 열이 있고 구역선 열은 없다.
- 상세를 열면 중국어·정기방문·작업 열이 숨고 카드·진행·인도자·유형·상태는 남는다.
- 1페이지 머리글 체크 후 삭제하면 1페이지 ID만 전달된다.
- 1페이지에서 선택한 뒤 2페이지로 이동하면 선택이 0개가 된다.
- `전체` 보기에서 머리글 체크하면 접히지 않은 필터 결과 전체만 선택된다.
- 구역선 없음 필터는 실제 경계가 없는 카드만 그린다.
- 페이지 이동 뒤 상세 패널은 새 페이지 첫 카드를 표시한다.

### 시각 확인

- 운영과 비슷한 긴 카드명·인도자·유형 수치로 데스크톱 일반 폭과 상세 패널 열린 폭을
  각각 캡처한다.
- 글자 겹침, 세로 쌓임, 페이지 전체 가로 스크롤이 없어야 한다.
- 1280px 및 1440px 데스크톱 뷰포트에서 확인한다.

## 7. 구현하지 않을 것

- 서버 쿼리 페이지네이션: 현재 데이터는 클라이언트에서 이미 한 번에 읽고 있으며,
  필터·Realtime 계약까지 바꾸는 별도 작업이다.
- 구역선 자료 삭제 또는 자동 배정 규칙 변경
- 필터 결과 전체를 화면에 숨긴 채 선택하는 기능
- 모바일 카드 목록 변경

## 리뷰 요청

다음을 중심으로 반례를 찾아 달라.

1. 현재 페이지 선택만 허용해도 기존 일괄 삭제·병합 계약이 깨지지 않는가.
2. 완료·제외 접기와 페이지 계산 순서가 맞는가.
3. Realtime 추가·삭제로 페이지 수가 바뀔 때 선택이나 상세가 다른 카드로 잘못 연결될 수 있는가.
4. `유형`을 되살리고 상세 열림 시 세 열을 숨기는 우선순위가 실제 업무에 맞는가.
5. 구역선 열을 없앤 뒤 누락을 찾고 수정하는 경로가 충분한가.
